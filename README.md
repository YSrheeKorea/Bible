# My Scripture (성경 앱)

React, Vite, 그리고 Tailwind CSS를 활용해 만든 모던하고 반응형을 지원하는 성경 읽기 애플리케이션입니다.

## 🌟 주요 기능

- **성경 읽기 (Bible Reader)**: 깔끔하고 집중하기 좋은 인터페이스에서 성경을 읽을 수 있습니다.
- **하이라이트 보드 (Highlights Board)**: 마음에 와닿는 구절을 저장하고 한곳에서 모아볼 수 있습니다.
- **QT 보드 (QT Board)**: 성경 구절을 묵상하고, 개인적인 생각이나 기도 제목을 기록할 수 있습니다.

## 🛠️ 기술 스택

- React 19
- Vite
- Tailwind CSS v4
- TypeScript

## 💻 로컬 개발 환경 설정

1. 이 저장소를 클론(Clone) 합니다.
2. `npm install` 명령어를 실행하여 의존성 패키지를 설치합니다.
3. `npm run dev` 명령어를 통해 로컬 개발 서버를 실행합니다.
4. 브라우저에서 `http://localhost:5173` 에 접속합니다.

## 🚀 배포 (GitHub Pages)

이 프로젝트는 GitHub Actions를 통해 GitHub Pages로 자동 배포되도록 설정되어 있습니다.
`main` 브랜치에 코드가 푸시되면 자동으로 빌드 및 배포 작업이 실행됩니다.
