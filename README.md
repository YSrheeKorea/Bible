# Bible App

A modern, responsive Bible reading application built with React, Vite, and Tailwind CSS.

## Features

- **Bible Reader**: Read the Bible with a clean, distraction-free interface.
- **Highlights Board**: Save and organize your favorite verses.
- **QT (Quiet Time) Board**: Reflect on verses and write down your thoughts and prayers.

## Tech Stack

- React 19
- Vite
- Tailwind CSS v4
- TypeScript

## Local Development

1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `npm run dev` to start the development server
4. Open `http://localhost:5173` in your browser

## Deployment (GitHub Pages)

This project is configured to be deployed automatically to GitHub Pages using GitHub Actions.
Any pushes to the `main` branch will trigger a deployment.
